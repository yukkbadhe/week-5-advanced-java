# Week 5 Assignment: Advanced Java

## 📌 Overview

This repository contains the **Week 5 Advanced Java Assignment**. The assignment focuses on important advanced Java concepts through simple practical programs.

## 🎯 Objective

The objective of this assignment is to understand and implement:

* Packages
* Interfaces
* Abstract Classes
* File Handling
* Multithreading Basics

## 📂 Tasks

### Task 1: Packages — Organizing Java Code

Created a custom package named `studentmanagement` containing a `Student` class.

**Concepts Used:**

* `package` keyword
* `import` keyword
* Custom packages
* Accessing classes from another package

### Task 2: Interface — Payment System

Created a `Payment` interface and implemented it using two classes:

* `UPIPayment`
* `CardPayment`

**Concepts Used:**

* Interface
* `implements` keyword
* Method implementation
* Abstraction

### Task 3: Abstract Classes — Shape Calculator

Created an abstract class `Shape` with an abstract method `calculateArea()`.

Child classes:

* `Circle`
* `Rectangle`

**Concepts Used:**

* `abstract` keyword
* Abstract methods
* Normal methods
* Inheritance using `extends`

### Task 4: File Handling — Student Records

Created a program to store student information in a text file and read the information back.

**Student Details:**

* Student ID
* Student Name
* Course
* Marks

**Concepts Used:**

* `FileWriter`
* `FileReader`
* `BufferedReader`
* Exception handling
* Writing and reading files

### Task 5: Multithreading Basics

Created two threads that perform different tasks:

**Thread 1:** Prints numbers from 1 to 10.

**Thread 2:** Prints "Learning Java Multithreading".

**Concepts Used:**

* `Thread` class
* `run()` method
* `start()` method
* Concurrent execution

## 🛠️ Technologies Used
